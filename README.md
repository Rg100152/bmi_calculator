## ✨ Features

- 💪 **Accurate BMI Calculation:** Uses standard BMI formulas for both **Imperial** (lbs/in) and **Metric** (kg/cm) units.
- 🏷️ **Health Categories:** Automatically classifies your BMI as **Underweight, Normal, Overweight, or Obese**.
- 🎨 **Classic Retro UI:** Authentic **Java Swing / Windows 95** visual style with beige background, raised 3D buttons, and sunken entry fields.
- 📋 **User Information:** Fields for Name and Age with default values.
- 🧮 **Unit Selection:** Choose between **lbs / in** or **kg / cm** using radio buttons.
- 🖱️ **Clear & Calculate:** Dedicated buttons to reset all fields or instantly calculate your BMI.
- 💾 **Data Saving:** Save your results to a file for later reference.
